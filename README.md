# 瀧洋科技｜CBCT 氣道服務潛在商機試算網站

## 開啟方式

1. 解壓縮整個資料夾。
2. 直接以 Chrome、Edge、Safari 等瀏覽器開啟 `index.html`。
3. 網站沒有使用外部 JavaScript 套件；樣式、互動腳本及 LOGO 都放在本資料夾內。

## 網站功能

- 響應式版型：桌機、平板與手機皆可使用。
- 兩階段互動試算：每月植牙／矯正病例量、CBCT 影像規格狀態。
- 自動計算年病例數與示意潛在商機，並顯示計算假設。
- 服務應用、OPZ 雲端平台概念及聯絡表單展示。
- 表單會進行基本欄位驗證並顯示完成訊息。

## 試算假設（可於 `script.js` 調整）

- 區間代表月病例數：5、15、30、45、60 位。
- 示意服務評估比例：35%。
- 示意單次服務金額：NT$12,000。
- 展示的大數字以最接近的 NT$100,000 四捨五入；明細另列未四捨五入的估算值。

以上為提案展示情境，並非實際營收預測或保證。請依已確認的商業假設、服務條件、設備規格與法規需求調整。

## 正式上線前需處理

- 聯絡表單目前只有前端驗證與展示確認，不會傳送或保存個資；正式上線前需接上經核准的後端表單／CRM，並加入隱私告知及安全措施。
- 確認實際服務內容、定價、病例適用條件、CBCT 影像規格與所有醫療相關文案。
- 網站目前將附件 AI 檔轉為透明 PNG 供瀏覽器使用；原始設計檔不會被修改。
